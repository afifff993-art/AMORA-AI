# AMORA

Advanced Multilingual Omni-purpose Responsive Assistant: a personal AI assistant
for Android (Flutter + Python FastAPI + Kotlin). Original design, inspired by
the idea of a futuristic assistant, with no copied branding.

**Status: Phase 1 of 10 (foundation + futuristic UI).** See `PROJECT_PROGRESS.md`.
